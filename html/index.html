Conteúdo principal

Clique em um item do menu para ver a explicação.

1. O que é HTML?

HTML é a linguagem que cria a estrutura de uma página web.

2. Tags

As tags marcam cada parte da página. Exemplo: <p> cria um parágrafo.

3. Links

A tag <a href="#"> cria um link para outra página ou parte da página.

4. O que é CSS?

CSS é a linguagem que deixa a página bonita, com cores, tamanhos e posições.

5. Cores no CSS

A propriedade background-color muda a cor de fundo e color muda a cor do texto.
